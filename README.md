# LIFE RPG — Back4Heart

Русскоязычное веб-приложение превращает большую цель в персональную RPG-кампанию. При первом запуске игровой проводник знакомится с игроком и проектом Back4Heart, сохраняет ответы, рассчитывает настраиваемые характеристики персонажа и собирает маршрут из этапов и квестов.

## Запуск

Нужен Node.js 20 или новее. Дополнительные зависимости не нужны.

```powershell
node server.mjs
```

Откройте <http://localhost:4173>. Проверки: `node --test`.

## Игровой цикл

- Последовательное интервью с сохранением после каждого ответа и возможностью продолжить после перезагрузки.
- Карточка персонажа с характеристиками, объяснением источника оценок и ручной настройкой.
- Предпросмотр кампании Back4Heart до запуска; измеримая цель, критерий успеха, сроки, 4 этапа и 12 квестов.
- Дашборд, интерактивная карта, отметки «выполнено / перенести / нужна помощь», XP, монеты, уровни и серия.
- Вечерний и недельный обзор. Изменение темпа показывается отдельно и применяется только по решению игрока.
- Редактирование профиля пересобирает открытые квесты, сохраняя завершённые, перенесённые и заблокированные.
- Компоновка адаптируется к широкому и узкому экрану.

## Данные и ограничения

Состояние версии 2 хранится в `localStorage` текущего браузера; миграция с версии 1 сохраняет игровой прогресс и старые кампании. Облачной синхронизации, аккаунтов, напоминаний и внешних интеграций нет.

Генератор — детерминированные локальные шаблоны и правила, не подключённая языковая модель. Он не угадывает предметную область Back4Heart: проект и желаемый результат задаёт игрок. Если браузер запрещает хранение, приложение предупредит, что продолжение после закрытия вкладки не гарантировано.
